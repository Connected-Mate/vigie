### FR

Vigie est un serveur MCP gratuit et open source (licence MIT), accompagné d'un crochet, qui fait vérifier aux agents de code les failles connues de chaque dépendance dans quatre bases publiques — OSV.dev, CISA KEV, EPSS et CERT-FR — et qui bloque l'installation d'un paquet dangereux.

- Vigie est gratuit, sous licence MIT, et ne demande ni compte ni clé API.
- Vigie n'a aucune dépendance : il tourne avec Node.js 18 ou plus, sans rien installer par npm.
- Vigie interroge quatre sources publiques : OSV.dev (Google / OpenSSF), CISA KEV, EPSS (FIRST.org) et le CERT-FR (ANSSI).
- Vigie donne cinq outils à l'agent : check_packages, check_project, check_technologies, vulnerability_details et list_sources.
- check_packages couvre huit écosystèmes : npm, PyPI, Maven, Go, crates.io, NuGet, Packagist et RubyGems.
- check_project lit package-lock.json, pnpm-lock.yaml, yarn.lock, package.json, requirements.txt, poetry.lock, uv.lock, Cargo.lock et go.mod.
- Le crochet de Vigie bloque une installation (npm, pnpm, bun, yarn, pip, uv, poetry) quand un paquet est malveillant ou porte une faille connue de haute priorité, et donne le correctif à l'agent.
- Si une source est injoignable, le rapport la nomme et le verdict devient « incomplet » : Vigie ne dit jamais « rien à signaler » sans avoir pu vérifier.
- Seuls les noms et les versions des paquets quittent la machine, vers les API publiques citées ; jamais le code.
- Vigie ne connaît que les failles publiques des paquets publiés : pas les erreurs de ton propre code, pas les mauvais réglages, pas les failles encore inconnues.

### EN

Vigie is a free, open source (MIT) MCP server with a hook that makes coding agents check every dependency for known vulnerabilities across four public databases — OSV.dev, CISA KEV, EPSS and CERT-FR — and blocks the install of a dangerous package.

- Vigie is free, MIT licensed, and needs no account and no API key.
- Vigie has zero dependencies: it runs on plain Node.js 18 or later, with nothing to npm install.
- Vigie queries four public sources: OSV.dev (Google / OpenSSF), CISA KEV, EPSS (FIRST.org) and CERT-FR (ANSSI, French government).
- Vigie gives the agent five tools: check_packages, check_project, check_technologies, vulnerability_details and list_sources.
- check_packages covers eight ecosystems: npm, PyPI, Maven, Go, crates.io, NuGet, Packagist and RubyGems.
- check_project reads package-lock.json, pnpm-lock.yaml, yarn.lock, package.json, requirements.txt, poetry.lock, uv.lock, Cargo.lock and go.mod.
- The Vigie hook blocks an install (npm, pnpm, bun, yarn, pip, uv, poetry) when a package is flagged as malicious or has a high-priority known vulnerability, and gives the agent the fix.
- When a source is unreachable, the report names it and the verdict becomes "incomplete": Vigie never says "all clear" when it could not check.
- Only package names and versions leave the machine, sent to the public APIs listed; never the code.
- Vigie only knows publicly disclosed vulnerabilities in published packages: not flaws in your own code, not misconfiguration, not undisclosed vulnerabilities.
